# PF Sales CRM

Sales lead management tool for PF.

## Features

- Lead pipeline (Kanban board)
- Drag-and-drop lead management
- Staleness tracking
- Dashboard with alerts  
- Activity logging
- Sample deal library

## Setup

1. Create new Supabase project
2. Run `supabase-crm-schema.sql`
3. Copy `.env.example` to `.env`
4. Add your Supabase credentials
5. `npm install`
6. `npm run dev`

## Deploy

Deploys automatically via Vercel when pushing to main branch.
